# Contributing

Contributions are welcome for technical corrections, platform changes, authoritative references, quick-reference improvements, broken links, and technically significant translation issues.

## Before Opening an Issue

Check `ERRATA.md`, existing Issues, official documentation, and whether the behavior is version-specific.

## Pull Requests

Keep pull requests focused on one topic.

The complete publication manuscript is maintained separately and is not part of the public repository.

## Security & Privacy

Sanitize command output and never publish passwords, API keys, access tokens, private keys, customer data, or confidential infrastructure information.
