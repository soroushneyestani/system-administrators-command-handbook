# Errata & Technical Corrections

This document contains verified corrections, clarifications, and important technical changes related to published editions of the **System Administrator's Command Handbook**.

The purpose of this file is to provide a transparent and continuously maintainable correction layer for the printed handbook.

---

## How Errata Are Handled

A reported issue is added here only after it has been reviewed and verified.

An erratum may include:

- Incorrect command syntax
- Incorrect or outdated examples
- Version-specific behavior changes
- Deprecated or removed commands
- Incorrect privilege requirements
- Incorrect platform information
- Misleading operational guidance
- Typographical errors that affect technical meaning
- Incorrect cross-platform equivalents
- Documentation reference changes

Minor cosmetic or stylistic differences that do not affect technical meaning may not be listed.

---

## Status Definitions

Each issue may use one of the following statuses:

- **Reported** — An issue has been submitted but not yet verified.
- **Verified** — The issue has been confirmed.
- **Corrected Online** — Companion documentation has been updated.
- **Scheduled for Next Edition** — The correction will be applied to a future print edition.
- **Closed** — No further action is required.

## Platform Changes After Publication

Not every change listed here represents an error in the original book.

Operating systems and administration tools continue to evolve after publication.

Examples include:

* Commands becoming deprecated
* Commands being removed
* New replacement tools
* Changed default behavior
* Package or module changes
* New operating-system releases
* Updated security recommendations

These changes may be documented separately as post-publication technical updates.

---

## Reporting an Issue

If you find a possible technical error, please open a GitHub Issue.

When reporting an issue, include as much of the following information as possible:

* Language edition
* Section or command name
* Page number, if applicable
* Operating system
* Operating-system version
* PowerShell or shell version, if relevant
* Command or example involved
* Observed behavior
* Expected behavior
* Link to authoritative documentation, if available

Please do not submit security-sensitive system information, private credentials, access tokens, internal hostnames, or confidential production data.

---

## Verification Policy

Corrections are evaluated against authoritative sources whenever possible, including:

* Microsoft Learn
* Official PowerShell documentation
* Linux manual pages
* Upstream project documentation
* Distribution documentation
* Apple documentation
* Local command help on the relevant platform

Community reports are valuable for identifying possible issues, but technical corrections should be independently verified before publication.

---

## Edition Policy

Corrections listed in this file may be incorporated into future editions of the handbook.

The existence of an erratum does not automatically create a new print edition.

Significant accumulated corrections, platform changes, or structural updates may instead become part of a later revised edition.
