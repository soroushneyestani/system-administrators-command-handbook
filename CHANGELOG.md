# Changelog

## 2026 — Complete Reconstruction

The original project was reopened and comprehensively rebuilt for modern system administration.

### Major Changes

- Rebuilt around modern system-administration workflows.
- Expanded into a cross-platform reference for Windows, PowerShell, Linux, and macOS.
- Added task-oriented cross-platform comparison.
- Expanded Windows, PowerShell, Linux/systemd, and native macOS coverage.
- Added lifecycle classification: Current, Legacy, Deprecated, Removed.
- Added privilege, operational, and safety guidance.
- Added practical administrator examples and authoritative references.
- Prepared English, German, and Persian editions.
- Created the public companion repository.

## 2014 — Original Final Edition

The original project reached its completed form in 2014.

## 2012 — Initial Version

The first version of the project was created in 2012.
