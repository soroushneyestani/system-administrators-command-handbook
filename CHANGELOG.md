# Changelog

All notable milestones and public changes to the System Administrator's Command Handbook project are documented here.

This project began in 2012, reached its original completed form in 2014, and was fully reconstructed in 2026 for modern cross-platform system administration.

---

## 2026 — Complete Reconstruction

The original project was reopened and comprehensively rebuilt for modern system administration.

This reconstruction is not a simple revision or reprint of the 2014 edition.

The technical structure, platform coverage, administrative workflows, examples, operational guidance, lifecycle information, and reference model were re-evaluated and redesigned.

### Major Changes

- Rebuilt the handbook around modern system-administration workflows.
- Expanded the project into a cross-platform reference covering:
  - Windows
  - PowerShell
  - Linux
  - macOS
- Introduced task-oriented cross-platform comparison.
- Added modern Windows and Windows Server administration tools.
- Expanded PowerShell coverage for administration, networking, storage, security, automation, and remoting.
- Updated Linux administration coverage for modern environments.
- Added systemd-oriented administration.
- Expanded Linux networking, storage, security, diagnostics, and package-management coverage.
- Added macOS as a first-class administration platform.
- Added native macOS system tools for:
  - services
  - storage
  - networking
  - security
  - configuration
  - software updates
  - diagnostics
  - user administration
  - backup and recovery
- Added command lifecycle classification:
  - Current
  - Legacy
  - Deprecated
  - Removed
- Added privilege and safety guidance.
- Added operational guidance for administrative use.
- Added practical administrator examples.
- Added authoritative documentation references.
- Added cross-platform quick-reference sections.
- Added detailed navigation and command-oriented indexing.
- Prepared three language editions:
  - English
  - Deutsch
  - فارسی
- Created the public companion repository for future:
  - errata
  - technical updates
  - quick references
  - selected examples
  - platform change notes

### Technical Baseline

The reconstructed edition uses a 2026 technical baseline for current Windows, PowerShell, Linux, systemd, and macOS administration.

---

## 2014 — Original Final Edition

The original version of the project reached its completed form in 2014.

The handbook reflected the command-line administration landscape and system-management tools available at that time.

This edition became the foundation from which the later 2026 reconstruction was conceived.

---

## 2012 — Initial Version

The first version of the project was created in 2012.

The original goal was to build a practical command reference for system administrators who needed fast access to administrative commands and system-management tools.

That original concept eventually evolved into the completed 2014 edition and later into the fully reconstructed 2026 handbook.

---

## Project Direction

The long-term goal of the project remains the same:

> Make command-line system administration faster to navigate, easier to compare, and more practical to use across different operating systems.

The 2026 reconstruction extends that idea into a modern cross-platform reference for Windows, PowerShell, Linux, and macOS.
